# Design Lens

Use this lens for UI/UX designs, screen specs, flows, prototypes, design reviews, and product copy in interfaces.

Find missing decisions in:

- Primary user goal and next action on each screen
- Entry, exit, back, cancel, undo, and recovery paths
- Empty, loading, error, permission, offline, and success states
- Mobile, overflow, long text, keyboard, and accessibility behavior
- Destructive actions, confirmations, review steps, and trust signals
- Copy, hierarchy, defaults, affordances, and disabled states
- Design-system constraints and reusable components

Good questions:

- What should the user see when there is no data, partial data, or failed data?
- What is the single primary action on this screen?
- What recovery path exists if the user makes a mistake?
