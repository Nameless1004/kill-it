# Work Spec Lens

Use this lens for implementation plans, engineering tasks, Linear/GitHub tickets, handoffs, and agent work orders.

Find missing decisions in:

- Scope boundary and definition of done
- Files, modules, APIs, or systems likely affected
- Migration, rollout, rollback, and compatibility requirements
- Tests, fixtures, mocks, and verification commands
- Sequencing, dependencies, and blocked work
- Ownership of decisions, review, release, and support
- Constraints: deadline, tech stack, performance, security, data, platform

Good questions:

- What behavior must remain unchanged after this work?
- What test or command proves the task is complete?
- If the change fails in production, what is the rollback path?
